# Java-Spring-MVC
Áp dụng mô hình MVC và kiến trúc Spring xây dựng một website
1. Công nghệ sử dụng

Backend: (Java)
Spring Boot
/Spring JPA
/Spring MVC
/Spring Security
/Spring Session

- Build tool: Maven


Frontend: HTML, CSS và Javascript

- View Engine: JSP

- AJAX để gọi APIs

Database: MySQL (phần mềm MySQL WorkBench)


2. Triển khai dự án

Dự án được chạy tại localhost và không triển khai lên hosting
